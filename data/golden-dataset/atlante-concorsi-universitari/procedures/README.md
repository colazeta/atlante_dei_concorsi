# Procedures coding area

This folder contains the structured CSVs for manually coded procedures.

## Files
- `procedures.csv`
- `documents.csv`
- `profile_requirements.csv`
- `evaluation_criteria.csv`
- `committee_members.csv`
- `candidates.csv`
- `committee_candidate_relations.csv`

## Rules
- Headers must remain aligned with `data/templates/atlante-concorsi-universitari/`.
- Do not add ad-hoc columns.
- If schema changes are needed, update docs + schema + template first, then this workspace.
- Use `procedure_id` consistently across all files.
