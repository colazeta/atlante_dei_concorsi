# QA reports guide

Store QA outputs and validation evidence here.

Examples:
- run output from `scripts/validate_golden_dataset.py`;
- manual QA checklist completion records;
- discrepancy reports and adjudication summaries.

## Suggested naming
`qa_<YYYYMMDD>_<batch_or_procedure>.md`
`validation_<YYYYMMDD>_<batch>.txt`
