# Review notes guide

Use this folder for reviewer notes that cannot fit cleanly in CSV fields.

Review notes should track:
- uncertainties;
- ambiguous document classification;
- uncertain name matching;
- missing documents;
- unresolved relation evidence;
- human review decisions.

## Suggested filename
`<procedure_id>__review_notes.md`

Each note should include date, reviewer id/initials, and decision status.
