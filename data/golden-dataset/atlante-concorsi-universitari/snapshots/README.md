# Source-page snapshot guide

Snapshots preserve what was visible on source pages at collection time.

A snapshot may include:
- saved HTML page;
- PDF list page;
- screenshot;
- manually copied page text;
- metadata file (URL, timestamp, collector, notes).

## Suggested naming
`<university_slug>__<procedure_id>__<YYYYMMDD>__<snapshot_type>.<ext>`

## Purpose
Support reproducibility and later review of documentary evidence.
