# 03 — Documentary taxonomy

## Controlled `document_type` values
- `call_notice`
- `correction`
- `deadline_extension`
- `committee_appointment`
- `admission_list`
- `exclusion_list`
- `evaluation_criteria`
- `minutes`
- `final_ranking`
- `winner_appointment`
- `acts_approval`
- `annulment`
- `litigation_related_document`
- `other`

## Minimum document metadata
Each document record stores:
- `document_id`
- `procedure_id`
- `document_type`
- `title`
- `source_url`
- `publication_date` (if available)
- `retrieval_date`
- `file_hash` (if available)
- `text_hash` (if available)
- `version`
- `official_source_flag`
- `notes`
