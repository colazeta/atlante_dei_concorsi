# 12 — Pilot university selection (5–8 universities)

## Selection principle
Prioritise **heterogeneity**, not statistical representativeness.

## Target composition
Select 5–8 placeholder institutions, for example:
- University A (public, large, north, dynamic site)
- University B (public, medium, centre, mixed archive)
- University C (private, small, south, static pages)
- University D (public, large, islands, albo portal)
- University E (private, medium, north, PDF list)

(Names above are illustrative placeholders only.)

## Selection dimensions
- public/private;
- geographic area;
- large/medium/small university;
- different website structures;
- availability of archive;
- apparent quality of publication practices;
- presence of different recruitment procedure types.

## Practical selection workflow
1. Build a longlist of 20 placeholder candidates (`University A` ... `University T`).
2. Score each candidate on each dimension using 0–2 scale.
3. Select the smallest subset satisfying maximum heterogeneity.
4. Document rationale in source registry notes.
5. Revisit selection after first 30 coded procedures.

## Exclusion rules
- Exclude institutions with inaccessible sources for prolonged periods.
- Exclude institutions where publication pages are empty in the chosen time window.
